### 🎯 Objetivo

O principal objetivo desta disciplina é compreender e aplicar conceitos de modelagem e programação para bancos de dados NoSQL orientados a grafos, com foco em:

- Modelagem de dados baseada em Nós (*Nodes*), Relacionamentos (*Relationships*), Propriedades (*Properties*) e Rótulos (*Labels*).
- Escrita e manipulação de consultas declarativas utilizando a linguagem **Cypher** (`MATCH`, `CREATE`, `MERGE`, `WHERE`, `RETURN`).
- Navegação e travessia de caminhos complexos (*Graph Traversals*) e busca de relacionamentos direcionados entre entidades.
- Agregação, filtragem e transformação de dados conectados para geração de insights em redes de dados.

### 🛠️ Tecnologias Utilizadas

- **Neo4j** (NoSQL / Banco de Dados Orientado a Grafos).
- **Cypher Query Language (CQL)** (Linguagem declarativa de consulta a grafos).
- **Neo4j Desktop / Neo4j Browser / Neo4j AuraDB** (Ambientes de execução, gerenciamento e visualização).
- **VS Code** (Editor de código para estruturação dos scripts `.cypher`).
